========= Hireready - A Job PLacement & Grooming Platform ===========

Types of Users
===============================================
1. user(applicants - ppl looking to get hired)
2. admin(company reps - looking to hire)
3. Superadmin(ME- i control everything)
===============================================

=============================================================================================================================================
Admin Workflow (producer - produces jobs, courses, quizzes these get saved in the database)
=============================================================================================================================================
-SignUp : some company rep signs up with the following info
	-> company name
	-> company location
	-> representative's name
	-> representative's role
	-> rep company email
	-> rep phone number
	-> password
	-> click sign up to get redirected to the dashboard

-LogIn : logs in with email and password

-Dashboard ->Overview(contains): total jobs posted/ Active jobs, Total courses/Popular courses, Total No. of Applicants, Pending Applicants
	   ->Jobs : displays jobs in order of the most applicants applied to it. Information presented as rows with following info
		-> job title
		-> job type
		-> job location
		-> number of applied applicants(with pass and fail numbers)
		-> salary
		-> active/inactive(status)
		->(there should be some sort options for sorting/filtering the rows using no. of applicants or status)

		  : (action)add a job, provides following info
		-> job title
		-> job type - (full/part/contract/intern)
		-> job location - (onsite/remote)
		-> salary 
		-> required skills - e.g.(react, java, python etc.)
		-> short description
		-> PRESS NEXT TO PROCEED TO ADD A QUIZ FOR THE JOB
			Quiz info
			-> title
			-> topics (which topics are being tested)
			-> add questions - select which topic it falls under (can select multiple)
					 - question type - mcq, t/f, text
					 - add the mark for the question
					 - (there should be a button to add questions initially and after each one)
			-> set pass mark
			-> set time limit
			-> PRESS POST JOB TO COMPLETE THE ADD JOB ACTION
		->Option to close close hiring, the job card disappears from the users dashboard

	   ->Quizzes : shows the number of active quizzes/total quizzes, provides info about
		-> title
		-> topics
		-> which job its for
		-> option to edit the questions/time limit
		-> option to close the quiz, if the job its in is closed this gets closed automatically

	   ->Applicants : (only candidates who pass are displayed)shows info about applicants who applied to the jobs posted by the company rep(admin)
		-> applied to which job
		-> name
		-> score percentage
		-> view CV
		-> approve/reject (action button)

	   ->Courses : click the add course, shows the courses posted by the company(e.g. google has courses), to add a course need to provide following info
		-> course title
		-> short description
		-> topics covered
		-> instructor (just the name, dont want to complicate)
		-> duration
		-> modules/lessons
		    
		     : the courses tab will display these infos in rows,
		->course title
		-> topics
		-> number of participants (will be ordered by popularity)
		-> duration
		-> status(active/closed)
		-> button to unlist the course

	   ->Logout : logs out of the dashboard gets redirected to the landing page/ admin signup

==============================================================================================================================================
User Workflow (consumer - consumes the jobs, courses, quizzes userDashboard loads these from the database, only produces the CV)
==============================================================================================================================================
-SignUp -> user signs up on our platform, provides following info:
		-> Full Name
		-> Email Address
		-> Phone Number
		-> password
		-> confirm password
		-> user now completes a survey with questions that builds the persons CV/porfolio
			Survey Questions:
				-> STEP 1 - Career Information
            --------------------------------
            -> Which technology field interests you most?
                - Web Development
                - Mobile Development
                - Data Science
                - Cybersecurity
                - Cloud & DevOps
                - UI/UX Design
                - Artificial Intelligence

            -> Which role are you targeting?
                - Frontend Developer
                - Backend Developer
                - Full Stack Developer
                - Mobile Developer
                - Data Analyst
                - Cybersecurity Analyst
                - etc.

            -> Current experience level
                - Beginner
                - Intermediate
                - Advanced

            -> Current status
                - Student
                - Fresh Graduate
                - Working Professional
                - Career Switcher

            STEP 2 - Skills & Technologies
            --------------------------------
            -> Select technologies you have used
                - HTML
                - CSS
                - JavaScript
                - React
                - PHP
                - Python
                - Java
                - C#
                - MySQL
                - MongoDB
                - Docker
                - Git
                - Linux
                - AWS
                - etc.

            -> Rate your confidence (1-5)
                - Programming
                - Databases
                - Problem Solving
                - Communication

            STEP 3 - Projects & Portfolio
            --------------------------------
            -> Have you completed any projects?
                - Yes / No

            -> If yes:
                - Project Name
                - Project Description
                - Technologies Used
                - GitHub Link (optional)

            -> Add Another Project button

            -> GitHub Profile URL
            -> LinkedIn Profile URL
            -> Portfolio Website URL (optional)

            STEP 4 - Education
            --------------------------------
            -> Education Level
                - Diploma
                - Bachelor's
                - Master's

            -> Institution Name

            -> Degree Program

            -> Expected/Completed Graduation Year

            STEP 5 - Professional Summary
            --------------------------------
            -> Tell us about yourself
               (short paragraph for CV summary section)

            STEP 6 - Goals & Preferences
            --------------------------------
            -> Primary Goal
                - Get a Job Quickly
                - Improve Skills Before Applying
                - Find an Internship
                - Explore Career Options

            -> Preferred Work Arrangement
                - Remote
                - Hybrid
                - On-site

            -> Preferred Employment Type
                - Full-time
                - Internship
                - Contract

            -> Weekly Learning Availability
                - Less than 5 hours
                - 5-10 hours
                - 10+ hours

        -> Survey submitted

        -> System generates a professional profile/CV

        -> User redirected to dashboard
